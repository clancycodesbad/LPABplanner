# BUG-001: Exam-clash detection is scoped to the current term only

> Generated by [Quality Playbook](https://github.com/andrewstellman/quality-playbook) v1.5.6 — Andrew Stellman
> Date: 2026-09-26 · Project: LPABplanner

## Summary

`Engine.getClashingSubjects` (`engine.js:64-92`) only checks for exam-time clashes when the semester being evaluated equals `currentTerm` (line 81). The lecture-clash check in the same function has no such restriction — it runs for every semester. A student planning subjects into any future semester gets no exam-clash protection at all, even when the exam-time data exists and would produce a valid clash warning if the same subjects were placed in the current term.

## Spec reference

README.md: "**Clash detection** — Warns when two subjects in the same active semester share a lecture night or exam time." No term-scoping caveat is stated for either clash type.

## The code

```js
// engine.js:64-92
getClashingSubjects(semesterList, semesterId, currentTerm) {
    const clashData = {};
    for (let i = 0; i < semesterList.length; i++) {
        for (let j = i + 1; j < semesterList.length; j++) {
            const s1 = semesterList[i];
            const s2 = semesterList[j];

            if (s1.lecture === s2.lecture) {
                // ... lecture clash recorded — no term restriction ...
            }

            if (semesterId === currentTerm && examTimesClash(s1.exam, s2.exam)) {
                // ... exam clash recorded — ONLY for currentTerm ...
            }
        }
    }
    return clashData;
}
```

## Observable consequence

A student using the onboarding wizard's "suggested pathway" feature (which explicitly plans 8 semesters ahead) or manually planning multiple semesters ahead receives zero exam-clash warnings for any semester except the single one currently active. Two subjects with an identical exam date-time placed in, say, `winter2028`, produce no warning — even though the exact same two subjects placed in `currentTerm` would be flagged immediately. This directly undermines the tool's stated purpose for the majority of its intended use (forward, multi-year planning).

## Depth judgment

This asymmetry is worth tracing further because it's not obviously a bug from reading `getClashingSubjects` in isolation — it only becomes suspicious when compared against the lecture-clash branch in the *same function*, which has no equivalent restriction. No comment, commit message, or documentation passage was found (searched `git log -- engine.js` and the full README) that explains why exam clashes specifically would need this restriction while lecture clashes don't. The two most plausible explanations are: (a) an intentional design choice — future terms' published exam timetables might be considered provisional/unreliable, so warning on them could mislead students — or (b) an oversight where the `semesterId === currentTerm` check was added for a since-superseded reason and never removed. This ambiguity is why the bug is recorded with `disposition: deferred` rather than a firm `code-fix`.

## The fix

A one-line change would remove the scoping entirely, matching the lecture-clash branch's behavior:

```diff
--- a/engine.js
+++ b/engine.js
@@ -78,7 +78,7 @@ export const Engine = {
                         clashData[s2.id].push(`Lecture clash on ${s2.lecture}`);
                 }
 
-                if (semesterId === currentTerm && examTimesClash(s1.exam, s2.exam)) {
+                if (examTimesClash(s1.exam, s2.exam)) {
                     if (!clashData[s1.id]) clashData[s1.id] = [];

                     if (!clashData[s1.id].includes(`Exam clash on ${s1.exam}`))
```

**This diff is a proposal, not an applied/validated fix.** It is withheld from `quality/patches/BUG-001-fix.patch` pending the maintainer's decision on whether the current-term-only scoping was intentional (see Depth judgment above and `quality/QUALITY.md`'s Human Gate). If the maintainer confirms this should be unscoped, this exact diff can be applied directly — it was checked for syntactic correctness by hand-tracing the surrounding braces and matches the existing lecture-clash branch's structure exactly.
